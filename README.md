# 🎬 Flixx App

A sleek and responsive front-end movie discovery app that uses [The Movie Database (TMDB)](https://www.themoviedb.org/) API to display trending movies and TV shows. Built using HTML, CSS, and JavaScript.

## 🌟 Features

- 🔍 Browse popular movies and TV shows
- 📄 View detailed information including posters, release dates, and overviews
- 🔁 Switch between movie and TV categories
- 💅 Fully responsive design with a clean UI
